## 1. Global Field Standards & Validation Rules

1. **Identifier Conventions:**
   * Generated as string UUIDs or prefixed IDs:
     * Reports: `rep-xxxxxxxx` (or standard UUIDv4)
     * Incidents: `inc-xxxxxxxx` (or standard UUIDv4)
     * Predictions: `pred-xxxxxxxx`
     * Overrides / Audit: `ovr-xxxxxxxx`
     * Calculations: `calc-xxxxxxxx`
     * Simulations: `sim-xxxxxxxx`
2. **Timestamps:**
   * Strictly ISO-8601 UTC strings formatted as `YYYY-MM-DDTHH:MM:SSZ` (e.g. `2026-09-26T14:40:00Z`).
   * Never store client local offsets or unix epoch integers in API contracts.
3. **Confidence Scores:**
   * Normalized float strictly in range `[0.0, 1.0]`. Nullable when confidence cannot be estimated.
4. **Coordinates & Geographic Policy (No-Hallucination Invariant):**
   * If an exact location cannot be verified, `latitude` and `longitude` MUST be `null`.
   * Never guess GPS coordinates. Raw text is preserved verbatim with `precision = "approximate"` or `"unknown"`.
5. **Synthetic Data Policy:**
   * Every synthetic report or simulator run MUST set `is_synthetic: true`. Real/manual reports have `is_synthetic: false`.

## 2. Entity Specifications

### 2.1 Raw Report (`RawReport`)
Represents an incoming dispatch from a citizen, caller, radio, or crisis simulator.

| Field Name | Type | Required? | Nullable? | Description / Allowed Values |
| :--- | :--- | :---: | :---: | :--- |
| `report_id` | `string` | **Yes** | No | Unique report identifier (UUIDv4). |
| `text` | `string` | **Yes** | No | Dispatch content (length: 3 to 4,000 characters). |
| `source` | `string` | **Yes** | No | Enum: `"manual"`, `"simulator"`, `"dataset"`, `"other"`. |
| `is_synthetic` | `boolean` | **Yes** | No | `true` if generated by simulator; `false` if manual. |
| `reported_at` | `string` | **Yes** | No | ISO-8601 UTC timestamp of report event. |
| `location_hint` | `LocationHint` | No | **Yes** | Pre-extracted or user-provided location hint. |
| `metadata` | `object` | No | **Yes** | Arbitrary key-value metadata (phone, channel, etc.). |

#### Sub-Schema: `LocationHint`
* `raw_text` (`string | null`, optional): Raw location text (e.g. `"near Patia square"`).
* `latitude` (`number | null`, optional): Geocoded latitude $[-90.0, 90.0]$.
* `longitude` (`number | null`, optional): Geocoded longitude $[-180.0, 180.0]$.
* `precision` (`string`, required): Enum: `"exact"`, `"approximate"`, `"unknown"`.

### 2.2 ML Prediction (`MLPrediction`)
Advisory intelligence emitted by Aryan's NLP pipeline.

| Field Name | Type | Required? | Nullable? | Description / Allowed Values |
| :--- | :--- | :---: | :---: | :--- |
| `report_id` | `string` | **Yes** | No | References originating `raw_reports.report_id`. |
| `model_version` | `string` | **Yes** | No | Model descriptor (e.g. `"all-MiniLM-L6-v2+heuristic-v1"`). |
| `incident_type` | `TypePrediction` | **Yes** | No | Extracted hazard category. |
| `urgency` | `UrgencyPrediction` | **Yes** | No | Feature-derived operational urgency tier. |
| `location` | `LocationPrediction`| **Yes** | No | Extracted location entity and coordinates. |
| `people_at_risk`| `RiskPrediction` | **Yes** | No | Extracted casualty/trapped count. |
| `required_response` | `Array<ResponseNeed>` | **Yes** | No | Array of needed responder services. |
| `entities` | `Array<EntityToken>` | **Yes** | No | Extracted named entities. |
| `embedding_reference`| `string \| null` | No | **Yes** | Reference ID or pointer to dense vector. |
| `embedding` | `Array<number>` | No | No | Normalized 384-dimensional dense vector (`all-MiniLM-L6-v2`) for cosine similarity. Optional internal ML $\to$ Backend field (distinguished from `embedding_reference` pointer). If absent, field is omitted rather than null. |
| `processing_status` | `string` | **Yes** | No | Enum: `"SUCCESS"`, `"PARTIAL"`, `"FAILED"`, `"NEEDS_REVIEW"`. |
| `warnings` | `Array<string>` | **Yes** | No | Array of fallback or diagnostic warnings. |

#### Sub-Schemas:
* `TypePrediction`:
  * `label` (`string | null`): Enum: `"FLOOD_FLASH_FLOOD"`, `"FIRE_WILDFIRE_EXPLOSION"`, `"STRUCTURAL_COLLAPSE"`, `"EARTHQUAKE_LANDSLIDE"`, `"SEVERE_WEATHER_STORM"`, `"MEDICAL_EMERGENCY"`, `"CIVIL_UNREST_ACTIVE_THREAT"`, `"UTILITY_INFRASTRUCTURE_FAILURE"`, `"OTHER_GENERAL_INCIDENT"`, or `null`.
  * `confidence` (`number | null`): Float $[0.0, 1.0]$.
* `UrgencyPrediction`:
  * `label` (`string | null`): Enum: `"CRITICAL"`, `"HIGH"`, `"MEDIUM"`, `"LOW"`, or `null`.
  * `confidence` (`number | null`): Float $[0.0, 1.0]$.
* `LocationPrediction`:
  * `text` (`string | null`): Extracted location phrasing.
  * `latitude` (`number | null`): Verified latitude or `null`.
  * `longitude` (`number | null`): Verified longitude or `null`.
  * `precision` (`string`): Enum: `"exact"`, `"approximate"`, `"unknown"`.
  * `confidence` (`number | null`): Float $[0.0, 1.0]$.
* `RiskPrediction`:
  * `count` (`integer | null`): Detected trapped/at-risk count.
  * `confidence` (`number | null`): Float $[0.0, 1.0]$.
* `ResponseNeed`:
  * `type` (`string`): Enum: `"SEARCH_AND_RESCUE"`, `"MEDICAL_EMS"`, `"FIRE_HAZMAT"`, `"POLICE_SECURITY"`, `"PUBLIC_WORKS_UTILITY"`.
  * `confidence` (`number | null`): Float $[0.0, 1.0]$.
* `EntityToken`:
  * `text` (`string`): Token substring.
  * `type` (`string`): Entity category (e.g. `"LOCATION"`, `"HAZARD"`, `"VICTIM"`, `"VEHICLE"`).
  * `confidence` (`number | null`): Float $[0.0, 1.0]$.

### 2.3 Incident (`Incident`)
The core operational unit in Karen's Ear representing a living, consolidated emergency.

| Field Name | Type | Required? | Nullable? | Description / Allowed Values |
| :--- | :--- | :---: | :---: | :--- |
| `incident_id` | `string` | **Yes** | No | Unique incident ID (UUIDv4). |
| `status` | `string` | **Yes** | No | Enum: `"NEW"`, `"ANALYZING"`, `"ACTIVE"`, `"NEEDS_REVIEW"`, `"VERIFIED"`, `"ESCALATED"`, `"RESOLVED"`, `"FALSE_REPORT"`. |
| `incident_type` | `string \| null` | **Yes** | **Yes** | Dominant crisis category. |
| `urgency` | `string \| null` | **Yes** | **Yes** | Current urgency tier: `"CRITICAL"`, `"HIGH"`, `"MEDIUM"`, `"LOW"`. |
| `location` | `IncidentLocation` | **Yes** | No | Tactical location object. |
| `people_at_risk` | `IncidentRisk` | **Yes** | No | Current assessed victims count. |
| `required_response`| `Array<string>` | **Yes** | No | List of required agency types. |
| `source_report_ids`| `Array<string>` | **Yes** | No | IDs of all raw reports fused into this incident. |
| `corroboration` | `Corroboration` | **Yes** | No | Corroboration metrics and explanation. |
| `ml_confidence` | `ConfidenceBlock`| **Yes** | No | Overall and component model confidences. |
| `priority` | `PriorityBlock` | **Yes** | No | Deterministic priority score and breakdown. |
| `human_override` | `HumanOverrideBlock`|**Yes**| No | Active human operator override details. |
| `is_synthetic` | `boolean` | **Yes** | No | `true` if incident was initiated by simulated data. |
| `created_at` | `string` | **Yes** | No | ISO-8601 UTC timestamp. |
| `updated_at` | `string` | **Yes** | No | ISO-8601 UTC timestamp of latest update. |

#### Sub-Schemas:
* `IncidentLocation`:
  * `text` (`string | null`)
  * `latitude` (`number | null`)
  * `longitude` (`number | null`)
  * `precision` (`string`): `"exact"`, `"approximate"`, `"unknown"`
* `IncidentRisk`:
  * `count` (`integer | null`)
* `Corroboration`:
  * `report_count` (`integer`, min 1): Total reports linked to incident.
  * `independent_source_count` (`integer`, min 1): Distinct eyewitness sources.
  * `score` (`number`, range $[0.0, 1.0]$): Saturating corroboration metric.
  * `explanation` (`string`): Plain-language summary.
* `ConfidenceBlock`:
  * `overall` (`number | null`, range $[0.0, 1.0]$)
  * `components` (`Record<string, number | null>`): Key-value confidence breakdown.
* `PriorityBlock`:
  * `score` (`number`, range $[0.0, 100.0]$): Ranked sorting metric.
  * `level` (`string`): Enum: `"CRITICAL"`, `"HIGH"`, `"MEDIUM"`, `"LOW"`.
  * `explanation` (`string`): Human-readable factor justification.
  * `factors` (`Array<PriorityFactor>`): Array of factor contributions.
* `PriorityFactor`:
  * `factor` (`string`): e.g. `"Urgency (Life-Safety)"`
  * `value` (`number | string`): e.g. `"CRITICAL"`
  * `weight` (`number`): e.g. `0.35`
  * `contribution` (`number`): e.g. `35.0`
* `HumanOverrideBlock`:
  * `active` (`boolean`): `true` if operator overrode any field.
  * `updated_by` (`string | null`): Operator identifier.
  * `updated_at` (`string | null`): ISO-8601 timestamp.
  * `reason` (`string | null`): Mandatory operator justification.

### 2.4 Incident-Report Relationship (`IncidentReportLink`)
Represents the join table between dispatches and incidents.

| Field Name | Type | Required? | Nullable? | Description / Allowed Values |
| :--- | :--- | :---: | :---: | :--- |
| `id` | `string` | **Yes** | No | Primary key UUID. |
| `incident_id` | `string` | **Yes** | No | Foreign key $\to$ `incidents.incident_id`. |
| `report_id` | `string` | **Yes** | No | Foreign key $\to$ `raw_reports.report_id`. |
| `relationship_type`| `string` | **Yes** | No | Enum: `"INITIAL"`, `"CORROBORATING"`, `"DUPLICATE"`, `"RELATED"`, `"UNCERTAIN"`. |
| `similarity_score` | `number \| null`| No | **Yes** | Cosine similarity at fusion time $[0.0, 1.0]$. |
| `fused_at` | `string` | **Yes** | No | ISO-8601 UTC timestamp. |

### 2.5 Audit Log (`AuditLog`)
Immutable ledger of all human modifications and administrative actions.

| Field Name | Type | Required? | Nullable? | Description / Allowed Values |
| :--- | :--- | :---: | :---: | :--- |
| `override_id` | `string` | **Yes** | No | Unique audit record UUID. |
| `incident_id` | `string` | **Yes** | No | Foreign key $\to$ `incidents.incident_id`. |
| `operator_id` | `string` | **Yes** | No | Identity of acting operator. |
| `field` | `string` | **Yes** | No | Overridden field (e.g. `"urgency"`, `"priority_score"`). |
| `previous_value` | `any` | **Yes** | **Yes** | State before operator modification. |
| `new_value` | `any` | **Yes** | **Yes** | State after operator modification. |
| `reason` | `string` | **Yes** | No | Mandatory justification string ($\ge 5$ chars). |
| `created_at` | `string` | **Yes** | No | ISO-8601 UTC timestamp. |
